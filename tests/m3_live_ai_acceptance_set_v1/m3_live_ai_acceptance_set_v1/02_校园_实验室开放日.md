# 从“路过”到“上手”：学院实验室开放日的一下午

周三下午两点，教学楼一层的走廊比平时热闹得多。原本紧闭的实验室门全部打开，示波器、机器人小车、无人机和开发板被摆到最显眼的位置。对很多低年级同学来说，这是第一次不隔着玻璃看设备，而是真正坐下来按下电源键。

## 第一站：把看不懂的波形调出来

电子实验室最受欢迎。桌上摆着函数发生器和示波器，老师没有先讲复杂原理，而是让大家完成一个非常具体的任务：把一个 1 kHz 正弦波稳定显示在屏幕中央。

一开始，大多数人的画面不是一条平稳曲线，而是一片上下跳动的波形。

> “先别急着问公式，先让仪器听你的话。”

调整触发、时基和垂直档位之后，屏幕上的波形终于稳定下来。这个瞬间比任何课件都更直观：原来课堂上的“频率”“幅值”和“触发”真的会对应到面板上的每一个旋钮。

## 第二站：一辆会“迷路”的小车

机器人实验室里，一辆循迹小车不断在黑线边缘摇摆。负责展示的学长故意把 PID 参数调得很差，让大家观察它如何过度修正。

同学们分成三组：

- 一组观察传感器数据；
- 一组调整控制参数；
- 一组记录每次修改后的表现。

十几分钟后，小车从“左右蛇形”变成了比较平稳的循迹。

## 比设备更重要的是人

开放日最有价值的部分并不是看到了多少昂贵仪器，而是很多平时没有机会问出口的问题终于有了具体对象。

“做电赛要提前学什么？”

“第一次进实验室应该从哪块板子开始？”

“不会焊接是不是就不适合做硬件？”

这些问题没有标准答案，但现场的人可以直接说出自己踩过的坑。

## 一张给第一次进实验室同学的小清单

如果下次再来，可以提前准备：

1. 带电脑和常用数据线；
2. 提前装好必要的软件和驱动；
3. 记录设备型号；
4. 遇到问题先描述现象，再猜原因；
5. 把当天做成功的一件小事保存下来。

下午五点，走廊重新安静下来。很多设备重新断电，但不少同学手机里已经多了几张波形截图、几段小车视频，以及一个比“我要学硬件”更具体的下一步。
