# 示波器波形不对时，先按这 6 步排查

在实验室里，最常见的情况不是“完全没有波形”，而是波形看起来哪里不对：幅值只有预期的一半、频率读数跳动、正弦波变形，或者屏幕上只有一条粗粗的亮带。

这时最容易犯的错误，是马上怀疑电路坏了。

## 第一步：确认探头和接地

先检查探头是否真正接到测量点，地夹是否接到系统参考地。

如果使用的是 ×10 探头，还需要确认：

```text
探头拨档 = ×10
示波器通道探头倍率 = ×10
```

两边设置不一致，会直接导致幅值读数错误。

## 第二步：确认输入耦合

常见耦合方式包括：

- DC：保留直流分量；
- AC：去掉直流分量；
- GND：用于观察零电平位置。

如果你正在测一个带直流偏置的信号，却误用了 AC 耦合，波形位置和低频成分都可能与预期不同。

## 第三步：把时基调到“能看懂”

不要一上来就依赖自动测量值。

对于一个 100 kHz 正弦波：

```text
周期 T = 1 / f = 10 μs
```

可以先把水平时基调整到每格 2–5 μs 左右，让屏幕出现几个完整周期。

## 第四步：检查触发

如果波形在屏幕上不停左右移动，通常不是信号频率在变化，而是触发没有锁定。

建议优先检查：

1. Trigger Source 是否选对通道；
2. Trigger Mode 是否合适；
3. Trigger Level 是否落在波形幅度范围内；
4. 上升沿/下降沿选择是否合理。

> 波形“站稳”以后，再谈测量值才有意义。

## 第五步：确认 50 Ω 与 High-Z

这是幅值异常最常见的来源之一。

如果信号源按照 50 Ω 负载标定，而实际示波器输入是 High-Z，端口电压可能与面板设定产生明显差异。反过来也一样。

因此必须明确：

| 项目 | 当前设置 |
| --- | --- |
| 信号源负载模式 | 50 Ω / High-Z |
| 示波器输入 | 50 Ω / High-Z |
| 线缆 | 50 Ω 同轴 |
| 被测电路输入阻抗 | 已确认 / 未确认 |

## 第六步：最后才判断电路本身

前五步确认无误后，再检查：

- 供电是否正确；
- 输入信号是否到达电路；
- 运放是否饱和；
- 滤波器截止频率是否正确；
- 是否存在接触不良。

如果每一步都记录现象，排错就会从“猜哪里坏了”变成一个可以逐层排除的问题。

**最重要的习惯不是会按哪个按钮，而是先验证测量链路，再验证被测对象。**
