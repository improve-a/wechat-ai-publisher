# 凌晨四点，城市还没有醒

凌晨四点的城市并不安静。

清洁车缓慢驶过路口，便利店的自动门偶尔打开，远处第一班公交还没有发车，但路边已经有人开始一天的工作。白天熟悉的街道在这个时间显得陌生：招牌还亮着，写字楼却没有声音，风吹过树叶时甚至能听见很细的摩擦声。

## 谁在这个时间醒着

早餐店老板把蒸笼一层层摞起来。面团提前醒好，豆浆机发出持续的低鸣。对他来说，四点不是“熬夜”，而是工作日正常的开始。

街角另一边，一名代驾刚结束最后一单。他没有马上回家，而是坐在台阶上看手机里的订单记录。

> 同一个时间，对一个人是一天的开始，对另一个人却是漫长一天的结尾。

城市的时间从来不是统一的。

## 白天看不到的秩序

我们习惯在白天理解一座城市：地铁拥挤、咖啡店排队、办公楼亮起一层层灯。但这些“正常运行”的背后，往往有另一套不被注意的时间表。

垃圾需要在人群出现前被清走，早餐需要在通勤开始前准备好，超市货架需要在开门前重新补满。

很多工作之所以显得不存在，只是因为它们恰好发生在我们看不见的时候。

## 关于效率的另一种理解

人们常把城市想象成一台追求效率的机器。但凌晨的街道提醒我们，效率并不意味着所有人同时工作。

恰恰相反，城市靠的是无数不同时间表互相咬合。

有人凌晨出门，有人中午换班，有人晚上十点才开始工作。正是这种错位，让一座拥有数百万人口的城市能够持续运转。

## 天亮之前

五点以后，天空开始发灰。

第一辆公交驶过路口，早餐店门口出现了第一个顾客。再过一个小时，人们会重新占满街道，城市也会恢复我们最熟悉的样子。

但如果只在白天认识它，我们看到的其实只是城市的一半。

那些在凌晨亮着的灯，并不是夜晚留下来的残影，而是另一群人已经开始的新一天。
